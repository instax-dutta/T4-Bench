# LLM, agent and training benchmarks on 2x T4

Measured campaigns extracted from the user's Kaggle T4 research notes.

## Sources
The original reports are preserved in `sources/`:
- `2x Tesla T4 Kaggle Benchmarks.md` — six-model chat/coding scoreboard, parallel-agent and tool-eval results.
- `Spark X2.5 Agentic Benchmark Report.md` — 1.7B vs 4B agent tasks and inference stats.
- `Ternary Bonsai 2 27B Benchmark Report.md` — single/dual T4 throughput and context-window limits.
- `Soup vs Unsloth Fine-Tuning Benchmark Tesla T4 2026.md` — memory, loss and OOM results for 8B QLoRA.

## Extracted data
`extracted.json` is generated by `../../scripts/extract_ruffbench.py`, which parses the markdown tables. It contains:
- chat model decode/prefill speed, VRAM and GPU count
- two-agent concurrency and tool-eval scores
- Spark agent task results and memory
- Ternary 27B single/dual GPU throughput and context points
- Soup vs Unsloth memory, loss and step-time rows

## Method
All reports used the same Kaggle machine: 2x Tesla T4 15 GB, 31 GB RAM, 4 vCPU. Exact prompts, seeds and versions are in each source report. The website reads only the extracted JSON, not the prose.

Source notes: personal research and benchmarking documents published at https://blog.sdad.pro/.
