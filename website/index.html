The memory wall

MiniMax-H3-Image needs far more memory than these cards have. Quantization makes it runnable, not fast.

The bars show how much memory the whole model needs. The measured 4096×4096 run used only the small image model plus a smaller text encoder and peaked at 14.6 GB on the GPU. The large text encoder ran out of memory, so the smaller one is required.
